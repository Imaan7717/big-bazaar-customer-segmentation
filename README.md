# Customer Segmentation Using K-Means Clustering

## Project Overview
This project focuses on segmenting customers into distinct groups using the K-Means Clustering algorithm. The objective is to identify customer purchasing patterns based on annual income and spending behaviour, helping businesses develop more effective marketing and promotional strategies.

## Problem Statement
Big Bazaar aims to divide its customers into meaningful segments to better understand their purchasing behaviour, improve customer engagement, and optimise promotional campaigns.

## Tools & Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## Methodology

1. **Data Collection:** Loaded the customer dataset for analysis.
2. **Data Preprocessing:** Inspected and prepared the dataset for clustering.
3. **Exploratory Data Analysis:** Examined customer characteristics and spending patterns.
4. **Model Development:** Implemented the K-Means Clustering algorithm.
5. **Optimal Cluster Selection:** Evaluated cluster configurations using the Elbow Method and Silhouette Score.
6. **Visualisation:** Used graphical representations to understand the resulting customer segments.
7. **Evaluation:** Analysed the clustering results and interpreted the customer groups.

## Key Objectives
- Identify distinct customer segments.
- Understand relationships between income and spending behaviour.
- Apply unsupervised machine learning techniques.
- Generate insights that can support business decision-making.

## Project Outcomes
The model groups customers into different clusters based on similarities in their characteristics and spending behaviour. These segments can help businesses design targeted marketing strategies and improve customer relationship management.
